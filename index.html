Analyse acoustique — enregistreur quatre voies

Choisissez un fichier de mesure pour calculer les niveaux en dB(A) et dB(C), le spectre en bande fine, le spectrogramme et leur évolution dans le temps. Tout le calcul se fait dans cette page, hors connexion, aucune donnée n'est transmise nulle part.

1. Fichiers de mesure (.WAV et .TXT)

Déposez le fichier audio (.WAV) et, si vous l'avez, le fichier de métadonnées (.TXT) — ensemble ou l'un après l'autre. S'il est fourni et que l'étalonnage y est renseigné, les niveaux s'affichent en dB SPL absolu, sinon l'analyse continue en dBFS relatif. Astuce : dans la boîte de dialogue, les deux fichiers peuvent être sélectionnés ensemble (Ctrl+clic) pour aller plus vite.

Déposez le ou les fichiers ici, ou cliquez pour les choisir
Outil autonome, aucune installation requise. Les calculs suivent la norme IEC 61672 pour les pondérations A et C.
