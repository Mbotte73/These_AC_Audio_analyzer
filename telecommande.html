Telecommande phyphox

Journal
Saisissez une seule fois le nom et l'adresse de chaque esclave (adresse affichee dans phyphox, onglet "Remote access", par exemple 192.168.43.23:8080). Tout est memorise sur ce telephone/navigateur.

Pour un vol : DEMARRER TOUT au decollage (demarre les esclaves ; le GPS du master se lance a la main, directement dans phyphox). A l'atterrissage, ARRETER TOUT arrete ET exporte automatiquement les donnees de chaque esclave (telechargees sur le master, au format CSV) — pour ne jamais oublier l'export. Les fichiers arrivent dans le dossier Telechargements du master ; il faudra les recuperer depuis le master a la fin de la journee (cable, Drive...), mais plus besoin d'aller sur les esclaves.

Entre deux vols, sans toucher les esclaves : une fois l'export automatique termine (voir le journal), appuyez sur "Effacer tout" pour vider la memoire de chaque esclave et repartir propre avant le vol suivant. Le bouton "Exporter tout" reste disponible separement si vous voulez re-exporter a un autre moment.
